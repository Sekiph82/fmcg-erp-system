## Repository expectations

- Preserve the existing architecture and naming conventions.
- Do not rewrite unrelated modules.
- Reuse existing shared components, services, and patterns.
- Run lint and relevant tests before finalizing changes.
- Keep changes modular and reviewable.
- For the Utilities Module, prefer incremental changes over broad refactors.
- Never break existing Production, Inventory, Finance, Quality, or Maintenance flows.
