## Troubleshooting

**Problem:** Page shows "Permission denied"  
**Solution:** Ask your admin to grant `[permission.view]` to your role.

**Problem:** Save button is greyed out  
**Solution:** Required fields (marked with *) are not filled. Complete all required fields.

**Problem:** Record not appearing in list  
**Solution:** Check if a filter is active. Clear all filters with the [Clear Filters] button.
