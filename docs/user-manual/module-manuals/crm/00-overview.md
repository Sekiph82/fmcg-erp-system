# CRM Module — Overview

**Route:** `/dashboard/crm`  
**Permission required:** `crm.view`

The CRM (Customer Relationship Management) module manages the full commercial pipeline from lead capture to won deal. It is organized into 12 tabs covering pipeline visibility, customer loyalty, NPS measurement, and survey management.

## Tab Summary

| Tab | Key | Description |
|---|---|---|
| Overview | `overview` | Dashboard KPIs, pipeline value, stage distribution, top reps |
| Pipeline | `pipeline` | Kanban board — drag-and-drop records between stages |
| Leads | `leads` | Lead records list with status and temperature filters |
| Opportunities | `opportunities` | Opportunity records with weighted pipeline calculation |
| Activities | `activities` | Activity timeline — calls, emails, visits, tasks |
| Forecast | `forecast` | Revenue forecast by month, stage, and rep |
| Territory | `territory` | Territory definitions and performance by rep |
| Stages | `stages` | Pipeline stage configuration and seed defaults |
| Win / Loss | `win-loss` | Closed deal analysis — win and loss reasons |
| Loyalty | `loyalty` | Customer points program — tiers, earn, and redeem |
| NPS | `nps` | Net Promoter Score tracking and survey responses |
| Surveys | `surveys` | Employee / customer survey lifecycle management |
