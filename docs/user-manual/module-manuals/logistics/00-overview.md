# Logistics Module — Overview

**Route:** `/dashboard/logistics`  
**Permission required:** `logistics.view`

## What It Does

The Logistics module manages the end-to-end international supply chain from Turkey to Kenya: shipment planning, container tracking, customs clearance at Mombasa port, trade document management, and domestic fleet operations.

![Logistics Overview](../../../screenshots/captured/module-ui/logistics/overview/overview-tab.png)
*Logistics overview showing KPI tiles, ETA alerts, and shipment pipeline.*

## Module Tabs

| Tab | Key | Description |
|-----|-----|-------------|
| Overview | `overview` | KPI dashboard, ETA alerts, active shipment pipeline |
| Shipments | `shipments` | International shipment planning and lifecycle management |
| Containers | `containers` | Container tracking by number, type, seal, and status |
| Arrivals | `arrivals` | Port arrival events, KRA customs clearance, local costs |
| Documents | `documents` | Customs documents — invoice, B/L, packing list, certificates |
| Fleet | `fleet` | Domestic vehicle fleet — drivers, trips, fuel, maintenance |
