# Point of Sale (POS) Module — Overview

**Route:** `/dashboard/pos`  
**Permission required:** `sales.view`

The POS module provides a full retail point-of-sale terminal directly within the ERP browser. It supports product search, cart management, multi-method payment, register session management, and daily sales history.

## Tab Summary

| Tab | Key | Description |
|---|---|---|
| POS Terminal | `pos` | Touch-friendly sales terminal with product grid and cart |
| Sales | `sales` | Daily sales history with void capability |
| Sessions | `sessions` | Register session log with opening/closing cash reconciliation |
