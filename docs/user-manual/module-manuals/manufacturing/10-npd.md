# New Product Development

**Route:** `/dashboard/npd`  
**Permission required:** `npd.view`  
**Workspace tabs:** New Products (single tab)

---

## What It Does

The NPD module manages the stage-gate pipeline for new product development — from an initial idea through concept, development, pilot trials, and commercial launch. Each project tracks the target market, estimated cost of goods, brand, and target launch date.

---

## NPD Dashboard

### KPI Cards

| Card | Description |
|------|-------------|
| Total Active | Count of all projects not in CANCELLED or LAUNCHED status |
| PILOT | Projects currently in the PILOT stage |
| LAUNCH | Projects in the LAUNCH stage (about to go live) |
| LAUNCHED | Projects that have reached commercial launch |

### Stage Pipeline Bar

Clickable filter chips for each stage:
- **All** — show all projects
- **IDEA** — initial idea; not yet validated
- **CONCEPT** — concept approved; preliminary costings started
- **DEVELOPMENT** — active R&D; formula trials underway
- **PILOT** — small-scale trial production run
- **LAUNCH** — final commercial approval; supply chain being set up
- **LAUNCHED** — live in the market
- **CANCELLED** — discontinued

Clicking a stage chip filters the project grid. Clicking the active chip again clears the filter.

---

## Project Card Grid

Projects are displayed as cards (not a table). Each card shows:
- `name` — project/product name
- `project_code` — system-generated reference in monospace font
- Stage badge (coloured by stage)
- `brand` chip (if set)
- `category` chip (with underscores replaced by spaces)
- `target_launch_date` — shown as "Target: YYYY-MM-DD"
- `estimated_cogs` — shown as "Est. COGS: KES {value}/unit"

Clicking a card navigates to the project detail page at `/dashboard/npd/{id}`.

## Creating an NPD Project

**Button:** `+ New Project` (requires `npd.create`)

### New Project Form Fields

| Field | Label | Required | Default | Notes |
|-------|-------|----------|---------|-------|
| `name` | Product Name | Yes | — | e.g. "New Mango Juice 500ml" |
| `category` | Category | Yes | `NEW_PRODUCT` | See category options below |
| `brand` | Brand | No | — | e.g. "POVU Naturals" |
| `target_market` | Target Market | No | — | e.g. "Kenya Urban" |
| `target_launch_date` | Target Launch Date | No | — | Date picker |
| `estimated_cogs` | Est. COGS/Unit (KES) | No | — | Decimal; e.g. `25.50` |
| `description` | Description | No | — | Brief summary |

**Submit** disabled until `name` is filled. A `project_code` is auto-generated by the backend on creation.

New projects start in `IDEA` stage automatically.

## NPD Project Detail Page

**Route:** `/dashboard/npd/{project_id}`

The detail page provides:
- Stage advancement controls (move project to next stage)
- Formulation trials linked to Recipes module
- BOM linkage (link the NPD project to a BOM once formula is approved)
- Cost modelling worksheets
- Gate review records (approval decisions at each stage gate)
- Document attachments (specifications, regulatory submissions)
- Task list for the R&D and commercialisation team

---

## Stage Gate Rules

Each stage gate requires specific documentation and approvals before advancing:

| Gate | From → To | Typical Requirements |
|------|-----------|---------------------|
| Gate 1 | IDEA → CONCEPT | Business case approved by NPD manager |
| Gate 2 | CONCEPT → DEVELOPMENT | Preliminary formula exists; market size confirmed |
| Gate 3 | DEVELOPMENT → PILOT | Formula approved; regulatory pre-check done |
| Gate 4 | PILOT → LAUNCH | Pilot trial passed; full costing complete; supply chain ready |
| Gate 5 | LAUNCH → LAUNCHED | First production run complete; trade launch confirmed |
