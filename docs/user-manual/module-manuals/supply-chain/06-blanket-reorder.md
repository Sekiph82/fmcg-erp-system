# Blanket Agreements, Reorder Policies & Suggestions

This chapter is a reference supplement to the RFQ chapter. See [03-rfq.md](./03-rfq.md) for full documentation of Blanket Agreements, Reorder Policies, and Procurement Suggestions.

**Quick reference:**

| Feature | Tab Key | Purpose |
|---------|---------|---------|
| Blanket Agreements | `blanket-agreements` | Pre-negotiated prices for a period; call-off orders |
| Reorder Policies | `reorder-policies` | Automatic reorder point triggers per material + warehouse |
| Suggestions | `suggestions` | AI + MRP generated procurement recommendations |
| Subcontracting | `subcontracting` | Outsourced manufacturing orders |
| Landed Cost | `landed-cost` | Allocate import costs across PO lines |
