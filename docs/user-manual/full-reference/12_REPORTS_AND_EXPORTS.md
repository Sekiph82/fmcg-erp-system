## Built-In Reports

Each workspace has an Export button (CSV/Excel/PDF). Built-in analytics reports:
- Sales by customer/product/region
- Inventory valuation
- Production output vs plan
- Procurement spend by supplier
- Payroll summary
- P&L summary

---

## Report Builder

Create custom reports without coding:
1. Analytics → Report Builder tab
2. Click **+ New Report**
3. Select data source
4. Choose columns (dimensions and metrics)
5. Add filters
6. Preview data
7. Save report with a name
8. Schedule: export via email (daily/weekly)

---

## Export Formats

| Format | Use Case |
|---|---|
| CSV | Data processing in Excel |
| Excel (.xlsx) | Formatted spreadsheet |
| PDF | Printable report |

All exports include the current filter state. Filters visible in the export header.
