# GAP-019 Shelf-Life / FEFO / Expiry Control — Audit

## Summary

Shelf-life and FEFO management is **substantially complete** at the model, service, and endpoint layers. The primary gaps are: (1) missing module-registry promotion (no permission codes generated), (2) FEFO enforcement is advisory-only at pick time, (3) stock-value-at-risk placeholder returns 0, and (4) temperature-adjusted and regulatory shelf-life rules are not implemented.

## What Is Missing / Gaps

### 1. Module Registry — CRITICAL
`shelf_life` is registered as `EndpointRouteDefinition`, not `ModuleDefinition`. No `permission_actions` → no permission codes generated by `registry_permission_codes()`. Module appears in routing but not in RBAC.

```python
# module_registry.py (current — wrong)
EndpointRouteDefinition(key="shelf_life", route_prefix="/shelf-life", ...)
```

**Fix**: Promote to `ModuleDefinition` with actions `("view", "create", "edit", "approve", "hold", "dispose", "report")`.

### 2. Seed Permissions — CRITICAL
No `shelf_life.*` permission tuples in `backend/app/db/seed.py`. Admin role does not include shelf-life permissions.

### 3. Nav-Config Guard
`frontend/src/components/nav-config.tsx` — shelf-life section guard needs audit. Likely uses a hardcoded string or `inventory.view` rather than `shelf_life.view`.

### 4. FEFO Enforcement Is Advisory Only
`validate_fefo_compliance` returns violations but does not block picks. There is no pick-time enforcement hook in the WMS pick endpoints. For FMCG/food safety this is a compliance risk.

**Decision (deferred)**: FEFO blocking enforcement requires WMS endpoint coordination. Document as known limitation; do not block GAP-019 on it.

### 5. Stock Value at Risk — Placeholder
`get_stock_value_at_risk` always returns 0. No cost/valuation data integrated from inventory/finance.

**Decision (deferred)**: Requires inventory costing data join. Document as known limitation.

### 6. Temperature-Adjusted Shelf Life
No temperature correction factor on `BatchShelfLifeRecord` or `ProductShelfLifeRule`. Cold-chain temperature deviations cannot shorten remaining shelf life automatically.

**Decision (deferred)**: Requires IoT/sensor integration. Document as known limitation.

### 7. Regulatory Shelf-Life Rules
No FDA/EU/Kenya-specific regulatory minimum shelf-life enforcement. `ProductShelfLifeRule` has `min_shelf_life_days` (operator-set) but no regulatory-floor enforcement.

**Decision (deferred)**: Regulatory rules are country-specific and require a rules engine. Document as known limitation.
